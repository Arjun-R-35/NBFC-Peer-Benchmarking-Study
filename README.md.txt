# NBFC Peer Benchmarking Study — Q1 FY27

## Project Overview
This project benchmarks five Indian Non-Banking Financial Companies (NBFCs) using selected financial indicators reported for Q1 FY27.

## Companies Covered
- Bajaj Finance
- Cholamandalam Finance
- Shriram Finance
- Muthoot Finance
- Five-Star Business Finance

## Metrics Analysed
- Gross Non-Performing Assets (GNPA) / Stage 3 assets
- Net Non-Performing Assets (NNPA) / Net Stage 3 assets
- Capital to Risk-Weighted Assets Ratio (CRAR)
- Assets Under Management (AUM) growth
- Return on Assets (ROA)
- Cost of Funds

## Tools Used
- Microsoft Excel for the web
- Excel formulas, tables, and charts

## Methodology
Figures were transcribed from company investor presentations and organized into raw-data, cleaned-data, and summary worksheets. The summary includes visual comparisons, key findings, and a conclusion.

## Limitations
Metric definitions and reporting periods may differ across companies. Some metrics were unavailable in the presentations reviewed. Missing values were left blank rather than treated as zero. AUM growth figures reported quarterly are not directly comparable with year-on-year growth figures.

## Files
- `NBFC_Benchmarking.xlsx` — benchmarking workbook
- Investor presentation PDFs — source documents used for data collection

## Disclaimer
This project is for educational and portfolio demonstration purposes only. It is not investment advice or a formal credit rating.
